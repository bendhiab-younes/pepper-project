# Présentation du SUJET 1 « Interactions vocales humain-robot »

Dans ce sujet, nous nous intéresserons à la problématique des systèmes d'interactions vocales humain-robot.

1. **Conférence (~1h)** — Une conférence présentera les enjeux majeurs du domaine : *« Les interactions vocales homme-machine, du rêve à la réalité... »*.
2. **Atelier (3h)** — Puis un premier atelier permettra la mise en oeuvre concrète des notions principales des systèmes d'interactions de type chatbot. Une solution actuelle de niveau professionnelle sera utilisée pour réaliser une tâche réaliste.
3. **Application** — Ensuite, le travail se poursuivra par une étude plus approfondie avec le développement d'une application de dialogue humain-robot basée sur une solution open-source état-de-l'art (intégrant des composants à base d'apprentissage automatique, ML) et s'interfaçant avec les robots Pepper de Softbank Robotics. De base il s'agira par exemple de réaliser une architecture complète pour un robot d'accueil du CERI : placé dans le hall, il pourra donner divers renseignements (emploi du temps, accès aux salles, salles libres...) et discuter de manière ouverte (météo, blagues, nouvelles...) avec les usagers (étudiants, personnels, invités...).

Les problématiques d'apprentissage automatique liées aux différents modules seront abordées, et ceux qui le souhaitent pourront entamer une étude d'apprentissage par renforcement avec Tensorflow/Keras pour optimiser la gestion du dialogue.
