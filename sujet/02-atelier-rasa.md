# Atelier — Mise en oeuvre d'un chatbot vocal sur le web (RASA)

> **Note :** Cet atelier n'est plus à faire depuis 2024. Il vous est donné à titre indicatif. Et vous devez seulement connaître les principes qu'il expose, sans l'avoir nécessairement fait.

## Mise en oeuvre d'un chatbot sur le web

Dans le contexte d'une découverte rapide du domaine des interactions vocales, nous vous proposons pour cette séance d'atelier de développer un chatbot sur une tâche simple en utilisant un outil performant et complet.

Cette étude sera approfondie dans la partie Application par la prise en main d'une solution open-source état-de-l'art sur une tâche impliquant un robot Pepper.

Parmi les outils professionnels, nous pouvons distinguer deux grandes catégories :

- **Les Majors**, issus des grands acteurs de l'informatique GAFA. Par exemple :
  - Chez Amazon : <https://aws.amazon.com/lex/>, plus tous les sites dédiés aux développements des Skills pour Alexa
  - Chez Microsoft : <https://dev.botframework.com/>, et là aussi la possibilité d'intégration avec Cortana
  - Chez Google : <https://dialogflow.com/>
- **Les start-ups**, une myriade de petits acteurs (plus ou moins) indépendants :
  - <https://wit.ai/>
  - <https://conversation.one/>
  - <https://snips.ai/>
  - <https://recast.ai/>
  - <https://www.botfuel.io/>
  - <https://flow.ai/>

Pour cette séance nous proposons d'utiliser la solution open-source **RASA**.

Les instructions pour la réalisation de l'atelier se trouvent sur ce github. Le dépôt contient aussi une partie des ressources nécessaires, qu'il peut être utile de pré-charger au démarrage (utiliser le bouton « Code » / « Download ZIP »).

> **Note :** pas de rendu pour l'atelier du défi, mais quelques questions du QCM final porteront sur des notions abordées lors de sa réalisation. Et ceux qui souhaitent poursuivre le travail dans l'Application pourront repartir de leur chatbot (donc ne pas l'effacer après l'atelier !).
